# Automation Integration

The renderer accepts structured scene data, selects a visual template, builds a deterministic timeline, renders the video, and produces a contact sheet plus a machine-readable report.

Minimum inputs:

- model name and formula;
- explanation goal and target audience;
- duration and output format; and
- visual template.

Every run should produce the resolved configuration, rendered video, contact sheet, render report, and review notes. Formula correctness, typography, layout, and motion rhythm remain explicit human review gates.
