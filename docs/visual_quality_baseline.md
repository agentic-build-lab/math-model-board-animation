# 视觉质量基线

本项目优先做“高级、震撼、克制、可复现”的数学模型动画。自动化只服务于更快复现高质量，不服务于低质量批量生产。

## 路线 A：震撼展示版

- 目标：3-8 秒内让观众觉得模型专业、强、有未来感。
- 线条：主体曲线 4 px，允许 8-10 px 柔和外发光；核心线必须清晰，外光不能糊成霓虹块。
- 填充：面积图高点透明度建议 90-120，底部 35-55；宁浅勿脏。
- 曲线高度：主峰不顶到标题，低谷不贴底轴；建议保留 10%-14% 上下安全空间。
- 公式位置：底部 72%-79% 高度区间，公式与图形之间要有呼吸感。
- 背景颗粒：微弱、低频、少量运动；禁止密集 HUD 网格抢主体。
- 动画节奏：标题 0.5 秒内入场，坐标轴 0.3 秒内建立，主体图形 1.3-2.4 秒生长。
- 色彩：黑底 + 冷白/青绿主信息 + 红/金局部强调，单屏强调色不超过两种。
- 空间层级：背景 < 坐标轴 < 填充 < 主线 < 高亮/公式。
- 舒适度：避免满屏高亮、快速闪烁、强对比大面积红色。

## 路线 B：教学推导版

- 目标：便于老师暂停讲解，公式和图形能自然解释模型。
- 线条：图形主体 3-4 px，坐标轴 2-3 px，推导辅助线 1-2 px。
- 发光：只作为层级提示，不作为装饰；教学版发光透明度建议低于展示版 30%。
- 填充：只辅助理解区域或分布，透明度控制在 35-90。
- 公式位置：可保留底部大公式，也可分步骤左到右/上到下排列；每屏最多一个主要认知动作。
- 字幕：使用短句，不遮挡公式和峰值；字幕区和公式区不要同时过满。
- 动画节奏：推导步骤可慢于展示版，每步出现后至少留 0.5-1.0 秒可读窗口。
- 色彩：变量高亮可用金色，结论可用青绿，错误/风险才用红色。
- 舒适度：优先可读、稳定、能暂停；不要用震动镜头和过强粒子。

## 当前 GARCH vNext 判断

- 曲线映射改为 10%-86% 垂直区间，避免旧版主峰过顶、填充过满。
- 填充从偏重红色改为浅层渐变，主线宽度略增加，外发光降低。
- 适合继续用 contact sheet 进行人工审美判断。
