# 核心视觉模板

## 共同底层规范

从旧项目复刻和参考片里保留下来的稳定规范：

- 黑底或极弱颗粒背景。
- 主体留白充足。
- 顶部章节标题居中。
- 坐标轴使用低亮白/灰白箭头轴。
- 不使用强网格和厚重面板。
- 公式放在图表下方或底部中间。
- 曲线边界比面积填充更重要。
- 强调色用于局部，不染满全屏。
- 动效以图形生长、公式出现和重点高亮为主，不做无意义镜头运动。

## 1. 黑板公式风

适用：

- 量化因子。
- 统计模型。
- 金融模型。
- 30-90 秒模型闪讲。

视觉：

- 背景：纯黑或弱颗粒。
- 主色：青绿 `#2ADDCB`。
- 曲线：暗红、白、青绿、金色。
- 字体：中文微软雅黑，公式 Cambria Math 或后续 LaTeX 渲染。
- 布局：顶部标题，中部图形，底部公式/字幕。

动效：

- 标题快速淡入。
- 坐标轴 0.2-0.4 秒出现。
- 公式整体淡入或短促 reveal。
- 曲线 1.5-2.8 秒生长。
- 峰值/区域短暂高亮。

避免：

- 大块高饱和红色填充。
- 密集网格。
- 过多解释文字。
- 每个公式都慢速逐字打字。

## 2. 现代科技风

适用：

- AI 模型。
- 神经网络。
- 系统架构。
- 多变量关系。
- 复杂数据流。

视觉：

- 背景：深黑到深灰，不用紫蓝渐变铺满。
- 主色：青绿、冷白，少量金色/紫色用于强调。
- 图形：节点、边、矩阵、嵌入空间、注意力权重。
- 布局：主体图形更大，公式可作为角落/底部辅助信息。

动效：

- 节点分层出现。
- 边按路径点亮。
- 矩阵块逐步显现。
- 关键路径 trace。
- 模型输入输出轻微流动。

避免：

- 科幻 HUD 过度装饰。
- 光效盖过结构。
- 难以读清的微小节点标签。
- 大面积单一紫蓝色。

## 3. 教学推导风

适用：

- 课程推导。
- 考试题讲解。
- 公式一步步变形。
- 概念从直觉到数学表达。

视觉：

- 背景：黑板、深灰板书或浅色纸面都可。
- 主体：公式行和少量辅助图。
- 布局：左到右或上到下推导，步骤编号清楚。
- 字体：更接近手写/板书，但必须清晰。

动效：

- 公式 step reveal。
- 变量逐个高亮。
- 等式两侧变形保持位置连续。
- 图形与公式同步标注。

避免：

- 过快闪过推导。
- 只展示最终公式。
- 每屏塞太多步骤。
- 字体为了手写感牺牲可读性。

## 4. 论文解读风

适用：

- 论文模型。
- 研究报告。
- 经济学/社会科学模型。
- 企业培训里的方法框架。

视觉：

- 背景：深色学术风或克制浅色论文风。
- 主体：模型框图、变量关系、公式、关键图表。
- 可使用论文截图局部，但必须重绘关键结构，不能只放截图。
- 布局：左侧模型结构，右侧解释/图表，或上下分区。

动效：

- 先显示研究问题。
- 再显示变量和假设。
- 逐步连接结构路径。
- 最后高亮结论或限制条件。

避免：

- 整页论文截图缩小到看不清。
- 过多引用文字。
- 像 PPT 翻页而不是模型解释。
- 用花哨动画掩盖逻辑关系。

## 模板优先级

第一阶段优先完成：

1. 黑板公式风。
2. 教学推导风。

第二阶段补齐：

3. 现代科技风。
4. 论文解读风。

原因：旧项目已经验证黑板公式风，教学推导风与其共用公式/坐标轴/高亮组件最多，最适合作为第二个稳定模板。
