# Reference Assets

Reference media is used only to study general composition, pacing, legibility, and motion patterns. It is not distributed unless its license explicitly permits redistribution.

Reusable observations include:

- dark backgrounds with restrained grain improve formula readability;
- a stable title, visualization, and formula hierarchy works across topics;
- curve growth, point reveals, and area transitions are effective reusable motions; and
- dense fills and decorative grid lines should not compete with the mathematics.

Do not copy account identities, watermarks, distinctive packaging, or protected text. Local reference files belong in ignored workspace directories and must never introduce personal machine paths into the repository.
